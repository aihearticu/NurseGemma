## TECHNICAL NOTES FOR RECORDING

### Screen Recording Setup:
1. Use 1920x1080 resolution
2. Show the NurseGemma UI clearly
3. Have Mrs. Johnson patient selected
4. Pre-load the UI to avoid loading delays

### Demo Preparation:
1. Clear any previous session data
2. Ensure all buttons are visible
3. Have sample outputs ready as backup
4. Test each workflow before recording

### Key Points to Emphasize:
- "Built BY a nurse, FOR nurses"
- Time savings displayed after each workflow
- The agentic nature (multiple MedGemma calls)
- Professional EPIC-style UI
- Clinical safety features

### Backup Demo Scenarios:
- If Lab Response fails: Use Shift Handoff
- If Family Explain fails: Use Quick Explain
- If Handoff fails: Use Progress Course
